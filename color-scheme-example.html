ASIF Foundation · Colour System

New scheme: green primary, orange accent, black only when needed

Re-anchored on ASIF green #09795b and orange #F7941D. The three big black blocks — stats bar, "How it works", footer — are now green-based, and orange is introduced as the accent that guides the eye. Black survives only as text and a deep green-black footer.

The palette

A disciplined system: one green family for structure, orange strictly for accents/CTAs, near-black reserved for text.

ASIF Green#09795bPrimary · buttons, headings, fills
Deep Green#055c45Gradients, dark headings
Forest#032b20Hero / dark section base
ASIF Orange#F7941DAccent · CTAs, numbers, steps
Orange Tint#FFF4E6Soft accent backgrounds
Green Tint#F1F8F5Section backgrounds
Green-Black#06251BFooter (replaces pure black)
Ink#2A2A2AText only — minimal fill

Action colours

Green is the default action; orange is the high-emphasis "Apply now" CTA so the most important click stands out.

Dùng thử miễn phí Đăng ký ngay · Apply now → Khám phá tính năng ↓

Rule of thumb: never more than one orange element competing in a viewport. Orange = "look here." Overuse and it stops meaning anything. All these tokens are now live in index.html.
